# สื่อวิดีโอการสอน: Arduino UNO Q (Ep.33 & Ep.35) กระบวนการ Deploy ไฟล์โมเดล (.eim) สู่บอร์ด Arduino UNO Q

## สาระสำคัญประจำคลิปวิดีโอ
กระบวนการโอนย้ายไฟล์ไบนารี .eim สู่ไดเรกทอรี /home/arduino/.arduino-bricks/ei-models/, การกำหนดสิทธิ์ chmod +x และการแก้ไขไวยากรณ์ไฟล์ app.yaml ภายใต้ตัวแปร variables: { ... } ตามคลิปถ่ายซ่อม Ep.35 (https://www.youtube.com/watch?v=0g2F-s-7O2U)
