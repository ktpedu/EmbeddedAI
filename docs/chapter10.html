SECTION 1

สาระสำคัญและผลการเรียนรู้ประจำบท

กรอบมาตรฐานการเรียนรู้ตามหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน และสมรรถนะสำคัญของผู้เรียน

สาระสำคัญ (Core Concept)

การจำแนกประเภทภาพ (Image Classification) ในสภาวะแวดล้อมจริงจำเป็นต้องอาศัยเทคนิค การเรียนรู้แบบถ่ายโอน (Transfer Learning) บนโครงข่ายประสาทเทียมแบบคอนโวลูชัน MobileNetV2 เพื่อช่วยลดเวลาในการฝึกสอนและคงความแม่นยำสูงแม้มีชุดข้อมูลจำกัด สิ่งสำคัญในการประยุกต์ใช้งานแบบเวลาจริงผ่านกล้องเว็บแคมคือ กลยุทธ์การจัดการคลาสฉากหลัง (Background Class Strategy) เพื่อป้องกันไม่ให้ฟังก์ชัน Softmax พยากรณ์คลาสผิดพลาดเมื่อไม่มีวัตถุเป้าหมายปรากฏหน้ากล้อง พร้อมทั้งการกำหนดค่าขีดเริ่มเปลี่ยนความมั่นใจ (Confidence Threshold) เพื่อให้ระบบทำงานได้อย่างเสถียรและแม่นยำ

ผลการเรียนรู้ที่คาดหวังตามกรอบสมรรถนะ (Learning Outcomes)

K ด้านความรู้และความเข้าใจ (Knowledge)

ผู้เรียนสามารถอธิบายหลักการของ Transfer Learning, โครงสร้างโมเดล MobileNetV2, การคำนวณความน่าจะเป็นด้วย Softmax และบทบาทสำคัญของคลาส Background ได้อย่างถูกต้องตามหลักวิชาการ

P1 ด้านทักษะการจัดการชุดข้อมูลภาพ (Dataset & Augmentation)

ผู้เรียนสามารถบันทึกภาพตัวอย่างสดผ่านกล้องเว็บแคม จัดหมวดหมู่ชุดข้อมูลภาพตามคลาสเป้าหมายควบคู่กับคลาสฉากหลังว่างเปล่า และเปิดใช้งาน Data Augmentation เพื่อป้องกัน Overfitting ได้อย่างถูกต้อง

P2 ด้านทักษะการประมวลผลภาพสด (Real-time Vision Inference)

ผู้เรียนสามารถติดตั้งโมเดลจำแนกภาพลงสู่บอร์ด UNO Q กำหนดค่าตัวแปร EI_CLASSIFICATION_MODEL ในไฟล์ app.yaml และเขียนโปรแกรมคัดกรองความมั่นใจเพื่อตรวจวัดความหน่วงเวลา (Latency) ได้อย่างสมบูรณ์

A ด้านคุณลักษณะและเจตคติ (Attitude & Values)

ผู้เรียนมีความละเอียดรอบคอบในการทดสอบระบบซ้ำหลายสภาวะแสง ตระหนักถึงความเสถียรของระบบตรวจจับที่ไม่สร้างการแจ้งเตือนเท็จ (False Triggering) และมีวินัยในการจัดเก็บข้อมูลภาพ

ส่วนที่ 2: สถาปัตยกรรมระบบ

สถาปัตยกรรมการจำแนกประเภทภาพด้วยการเรียนรู้แบบถ่ายโอน (Image Classification Architecture)

โครงสร้างการส่งผ่านข้อมูลจากกล้องเว็บแคมผ่านชั้นสังวัตนาการของ MobileNetV2 สู่การกระจายความน่าจะเป็น Softmax

รูปที่ 10.1: แผนภาพสถาปัตยกรรมโครงข่ายประสาทเทียม MobileNetV2 และการประมวลผลผ่าน Image Classification Brick บนระบบสมองกลฝังตัว

การเปรียบเทียบภารกิจด้านการมองเห็นของคอมพิวเตอร์ (Computer Vision Tasks):

ภารกิจ (Task) ผลลัพธ์ที่ได้ (Output) สถาปัตยกรรมโมเดล การใช้งานที่เหมาะสม
Image Classification (บทที่ 10) ฉลากหมวดหมู่ 1 คลาส + ความน่าจะเป็น MobileNetV1 / MobileNetV2 จำแนกชนิดชิ้นส่วนเดี่ยวบนถาดตรวจ
Object Detection (บทที่ 8-9) พิกัดจุดกึ่งกลาง (Centroid) + ฉลากหลายชิ้น FOMO (MobileNetV2 0.35) ตรวจนับและคัดแยกชิ้นงานหลายชิ้นบนสายพาน
Visual Anomaly Detection (บทที่ 5-7) ค่าความผิดปกติ (Anomaly Score) FOMO-AD (GMM Feature Extraction) ตรวจหาตำหนิหรือสิ่งแปลกปลอมบนพื้นผิว
ตอนที่ 1 (EP.1)

การเรียนรู้แบบถ่ายโอน (Transfer Learning) และโครงสร้างโมเดล MobileNetV2

การนำองค์ความรู้จากโครงข่ายประสาทที่ผ่านการฝึกสอนบนชุดข้อมูลขนาดใหญ่มาปรับประยุกต์ใช้งานบนอุปกรณ์ขอบ

การฝึกสอนโครงข่ายประสาทเทียมสำหรับการประมวลผลภาพตั้งแต่เริ่มต้น (Training from scratch) จำเป็นต้องใช้ภาพตัวอย่างจำนวนหลายหมื่นภาพและคอมพิวเตอร์สมรรถนะสูง แต่ในการพัฒนาบนระบบสมองกลฝังตัว เราใช้เทคนิค การเรียนรู้แบบถ่ายโอน (Transfer Learning) โดยนำโครงข่าย MobileNetV2 ที่ผ่านการฝึกฝนล่วงหน้า (Pre-trained) บนชุดข้อมูลสากล ImageNet (มากกว่า 1.4 ล้านภาพ) มาเป็นฐานในการสกัดคุณลักษณะเด่น (Feature Extractor)

ใช้ภาพจำนวนน้อย

ต้องการภาพเพียง 50–100 ภาพต่อคลาส ก็สามารถฝึกสอนโมเดลให้มีความแม่นยำสูงได้ เพราะชั้นล่างได้เรียนรู้เส้น ขอบ และรูปทรงเรขาคณิตมาแล้ว

ฝึกสอนรวดเร็ว

เราทำการตรึงน้ำหนัก (Freeze Weights) ของชั้นสกัดคุณลักษณะ และปรับจูนเฉพาะชั้นจำแนกผลลัพธ์ (Classification Head) ทำให้การฝึกสอนเสร็จสิ้นภายใน 2–5 นาที

ขนาดกะทัดรัด

สถาปัตยกรรม Depthwise Separable Convolution ทำให้โมเดลมีขนาดไบนารีเพียง 1.5–3.5 MB เหมาะสำหรับชิปประมวลผลของบอร์ดพัฒนา Arduino UNO Q

ตอนที่ 2 (EP.2)

กลยุทธ์การจัดการคลาสฉากหลัง (Background Class Strategy)

การแก้ปัญหาการทำนายผิดพลาดเมื่อไม่มีชิ้นงานอยู่หน้ากล้อง (Closed-world Assumption Problem)

โมเดลจำแนกประเภทภาพที่ใช้ฟังก์ชัน Softmax มีข้อจำกัดสำคัญคือ "ผลรวมของความน่าจะเป็นทุกคลาสต้องเท่ากับ 1.0 (100%) เสมอ" หากเราฝึกสอนเฉพาะคลาสชิ้นงาน เช่น Capacitor, Resistor, IC_Chip โดยไม่มีคลาสฉากหลัง ในเวลาที่ไม่มีวัตถุอยู่หน้ากล้อง (ฉากหลังว่างเปล่า) โมเดลจะถูกบีบให้สุ่มเลือกชิ้นงานใดชิ้นงานหนึ่งที่มีคะแนนสูงสุดเสมอ ก่อให้เกิดข้อผิดพลาด False Positive อย่างรุนแรง

รูปที่ 10.2: การจัดเตรียมชุดข้อมูลบน Edge Impulse Studio พร้อมการกำหนดหมวดหมู่ฉากหลังว่างเปล่า (Background)
แนวทางปฏิบัติที่ดีที่สุด (Best Practice):

ต้องเก็บภาพฉากหลังที่ว่างเปล่าในหลากหลายสภาพแสง (เช่น แสงไฟเปิด แสงไฟหรี่ เงาตกกระทบ มือผู้ปฏิบัติงานที่ว่างเปล่า) และตั้งชื่อคลาสว่า Background โดยให้มีสัดส่วนประมาณ ร้อยละ 20–25 ของชุดข้อมูลทั้งหมด

ตอนที่ 4 (EP.4)

การคำนวณ Softmax และการตรวจวัดความหน่วงเวลาในการประมวลผล (Inference Latency)

การแปลงคะแนนลอจิต (Logits) สู่ค่าความน่าจะเป็น และเทคนิคการวัดสมรรถนะความเร็วแบบเวลาจริง

ฟังก์ชันการแจกแจงความน่าจะเป็น Softmax (Softmax Probability Function):
P(y = i \mid \mathbf{x}) = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}

เมื่อ z_i คือค่า Logit ของคลาสที่ i และ K คือจำนวนหมวดหมู่ทั้งหมดในระบบ

การวัดความหน่วงเวลาในการประมวลผล (Inference Latency)

เวลาที่ใช้ในการประมวลผลโมเดลต่อ 1 เฟรม คำนวณจากผลต่างของเวลายูนิกซ์:

latency_ms = (t_end - t_start) * 1000.0

ค่ามาตรฐานบน Arduino UNO Q สำหรับโมเดล MobileNetV2 0.35 จะอยู่ที่ประมาณ 25–35 มิลลิวินาที (ms)

อัตราเร็วเฟรมภาพ (Frame Rate - FPS)

จำนวนเฟรมภาพที่ระบบสามารถรับภาพและพยากรณ์ผลลัพธ์ได้ใน 1 วินาที:

FPS = total_frames / elapsed_seconds

อัตราเร็วที่เหมาะสมสำหรับงานสายพานคัดแยกชิ้นงานควรอยู่ที่ 20 FPS ขึ้นไป

สคริปต์ไพทอนฉบับสมบูรณ์ รองรับการทำงานทั้งบนบอร์ดพัฒนา Arduino UNO Q และโหมดจำลองคอนโซล

code_examples/chapter10/image_classify_live.py 
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
import sys, time

try:
    from arduino.app_bricks.image_classification import ImageClassification
    from arduino.app_utils import App
    IS_ARDUINO_ENV = True
except ImportError:
    IS_ARDUINO_ENV = False


class LiveImageClassifier:
    """คลาสจัดการผลการจำแนกประเภทภาพแบบเวลาจริงและการคำนวณสถิติ"""
    def __init__(self, confidence_threshold=0.80):
        self.threshold = confidence_threshold
        self.summary_stats = {"Capacitor": 0, "Resistor": 0, "IC_Chip": 0, "Background": 0}

    def process_result(self, result, latency_ms=32.0):
        if not result:
            return

        top_label = result.get("label", "Unknown")
        confidence = result.get("confidence", 0.0)
        scores = result.get("scores", {})

        # 1. คัดกรองกรณีฉากหลังว่างเปล่า
        if top_label.lower() in ["background", "nothing", "none"]:
            self.summary_stats["Background"] += 1
            print(f"[-] ฉากหลังว่างเปล่า (Background: {confidence*100:.1f}%) | Latency: {latency_ms:.1f} ms")
            return

        # 2. ตรวจสอบเกณฑ์ความเชื่อมั่นขั้นต่ำ
        if confidence >= self.threshold:
            self.summary_stats[top_label] = self.summary_stats.get(top_label, 0) + 1
            print(f"\n[+] [MATCH] จำแนกพบ: '{top_label}' | ความเชื่อมั่น: {confidence*100:.2f}% | Latency: {latency_ms:.1f} ms")
            score_str = ", ".join([f"{k}: {v*100:.1f}%" for k, v in scores.items()])
            print(f"    -> Softmax: [{score_str}]")
        else:
            print(f"[?] ความเชื่อมั่นไม่เพียงพอ ({top_label}: {confidence*100:.1f}% < {self.threshold*100:.0f}%)")

คำถามทบทวนองค์ความรู้ท้ายบทเรียน (Review Questions)

ทดสอบความเข้าใจเชิงลึกเกี่ยวกับหลักการจำแนกภาพและการประยุกต์ใช้งานบนระบบสมองกลฝังตัว

1. การจำแนกประเภทภาพ (Image Classification) แตกต่างจากการตรวจจับวัตถุ (Object Detection) ในแง่ของข้อมูลอินพุตและผลลัพธ์เอาต์พุตอย่างไร และงานลักษณะใดจึงควรเลือกใช้ Image Classification?
คลิกเพื่อดูแนวคำตอบ
แนวคำตอบ: Image Classification จะพิจารณาภาพรวมทั้งภาพและทำนายว่าภาพนั้นคือวัตถุหมวดหมู่ใดเพียง 1 คำตอบหลัก พร้อมความน่าจะเป็น โดยไม่ระบุตำแหน่งหรือพิกัดบนภาพ ในขณะที่ Object Detection จะสามารถระบุได้ว่ามีวัตถุอะไรบ้าง อยู่ตำแหน่งใด (พิกัด Centroid หรือ Bounding Box) และมีกี่ชิ้นพร้อมกันใน 1 ภาพ งานที่เหมาะกับ Image Classification คือกรณีที่มีวัตถุเป้าหมายวางอยู่ตรงกลางเฟรมทีละ 1 ชิ้น เช่น จุดตรวจสอบคุณภาพชิ้นส่วนอิเล็กทรอนิกส์บนถาดนิ่ง ซึ่งช่วยประหยัดหน่วยความจำและประมวลผลได้รวดเร็วกว่า
2. หากไม่สร้างคลาสฉากหลังว่างเปล่า (Background Class) ในชุดข้อมูลฝึกสอน จะส่งผลกระทบต่อการทำงานของระบบจำแนกภาพแบบเวลาจริงอย่างไร และเพราะเหตุใดฟังก์ชัน Softmax จึงทำให้เกิดปัญหานี้?
คลิกเพื่อดูแนวคำตอบ
แนวคำตอบ: ฟังก์ชัน Softmax จะบีบให้ผลรวมของความน่าจะเป็นของทุกคลาสรวมกันได้เท่ากับ 1.0 (100%) เสมอ หากไม่มีคลาส Background เมื่อไม่มีวัตถุวางอยู่หน้ากล้อง โมเดลจะถูกบังคับให้กระจายคะแนนไปยังคลาสชิ้นงานที่มีอยู่ ทำให้คลาสชิ้นงานใดชิ้นงานหนึ่งได้คะแนนสูงสุดและเกิดการแจ้งเตือนผิดพลาด (False Positive) อย่างต่อเนื่อง การเพิ่มคลาส Background ทำให้โมเดลมีทางเลือกในการทำนายเมื่อไม่มีวัตถุเป้าหมายปรากฏ
3. ในไฟล์ app.yaml ตัวแปร EI_CLASSIFICATION_MODEL ทำหน้าที่อะไร และการกำหนด CONFIDENCE_THRESHOLD มีผลต่อความแม่นยำและความเร็วของระบบอย่างไร?
คลิกเพื่อดูแนวคำตอบ
แนวคำตอบ: ตัวแปร EI_CLASSIFICATION_MODEL ทำหน้าที่กำหนดตำแหน่งพาธสัมบูรณ์ของไฟล์ไบนารีโมเดล (.eim) เพื่อให้ Image Classification Brick โหลดเข้าสู่หน่วยความจำ ส่วน CONFIDENCE_THRESHOLD (เช่น 0.80) ทำหน้าที่เป็นตัวกรองขั้นสุดท้าย โดยระบบจะยอมรับผลการทำนายและส่งสัญญาณปฏิบัติการเฉพาะเมื่อโมเดลมีความเชื่อมั่นตั้งแต่ร้อยละ 80 ขึ้นไปเท่านั้น ช่วยตัดสัญญาณรบกวนในจังหวะที่วัตถุกำลังเคลื่อนที่เข้าสู่เฟรมกล้อง
