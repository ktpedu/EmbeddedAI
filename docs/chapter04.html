SECTION 1

สาระสำคัญและผลการเรียนรู้ประจำบท

กรอบมาตรฐานการเรียนรู้ตามหลักสูตรแกนกลางการศึกษาขั้นพื้นฐาน และสมรรถนะสำคัญของผู้เรียน

สาระสำคัญ (Core Concept)

ในกระบวนการพัฒนาปัญญาประดิษฐ์และระบบการเรียนรู้ของเครื่อง ความถูกต้องและแม่นยำของโมเดลปลายทางขึ้นอยู่กับคุณภาพและการออกแบบ ขั้นตอนการประมวลผลข้อมูล (Data Pipeline) เป็นสำคัญ การจัดเตรียมข้อมูลภาพจำเป็นต้องมีการกำหนดเกณฑ์มาตรฐานอย่างเป็นระบบ ตั้งแต่การเก็บรวบรวมภาพในสภาวะแวดล้อมจริง (Data Acquisition) การแบ่งสัดส่วนชุดข้อมูลฝึกสอน (Training Set) ต่อชุดข้อมูลทดสอบ (Testing Set) ในอัตราส่วน 80:20 เพื่อป้องกันปัญหาการท่องจำข้อมูล (Overfitting) การเลือกวิธีการติดป้ายกำกับ (Labeling Method) ให้ถูกต้องตามประเภทของสถาปัตยกรรมโมเดล และการปรับขนาดความละเอียดภาพให้เหมาะสมกับขีดจำกัดหน่วยความจำของอุปกรณ์สมองกลฝังตัว (TinyML Optimization)

ผลการเรียนรู้ที่คาดหวังตามกรอบสมรรถนะ (Learning Outcomes)

K ด้านความรู้และความเข้าใจ (Knowledge)

ผู้เรียนสามารถอธิบายหลักการออกแบบขั้นตอนการประมวลผลข้อมูล (Data Pipeline), ความสำคัญเชิงสถิติของการแบ่งชุดข้อมูล 80:20 และความแตกต่างระหว่างการติดป้ายกำกับแบบจำแนกประเภทกับแบบกำหนดพิกัดขอบเขต (Bounding Boxes) ได้อย่างถูกต้อง

P1 ด้านทักษะการเก็บรวบรวมและจัดระเบียบข้อมูล (Data Acquisition)

ผู้เรียนสามารถเชื่อมต่อกล้องดิจิทัลเข้ากับแพลตฟอร์ม Edge Impulse Studio บันทึกภาพตัวอย่างชิ้นงานได้อย่างหลากหลายมุมมอง และจัดสัดส่วน Train/Test ได้ตามเกณฑ์มาตรฐาน

P2 ด้านทักษะการติดป้ายกำกับและการประมวลผลภาพ (Labeling & Preprocessing)

ผู้เรียนสามารถวาดกรอบ Bounding Box ระบุตำแหน่งวัตถุ กำหนดขนาดความละเอียดอินพุต 96x96 พิกเซล และเขียนสคริปต์ตรวจสอบความสมดุลของข้อมูลได้อย่างถูกต้อง

A ด้านคุณลักษณะและเจตคติ (Attitude & Values)

ผู้เรียนมีความซื่อสัตย์ทางวิชาการในการไม่ปะปนข้อมูลทดสอบกับข้อมูลฝึกสอน (Data Leakage Prevention) มีความประณีตในการติดป้ายกำกับ และคำนึงถึงจริยธรรมข้อมูลส่วนบุคคล

ตอนที่ 1: ขั้นตอนการประมวลผลข้อมูล

สถาปัตยกรรมขั้นตอนการประมวลผลข้อมูลบน Edge Impulse (Data Pipeline Architecture)

คำว่า "ขั้นตอนการประมวลผลข้อมูล" (Data Pipeline) หมายถึง ชุดของกระบวนการเชิงลำดับที่นำพาข้อมูลดิบ (Raw Data) จากแหล่งกำเนิด ผ่านการคัดกรอง ทำความสะอาด แปลงสภาพ และจัดระเบียบ จนกระทั่งพร้อมเข้าสู่กระบวนการสกัดคุณลักษณะเด่น (Feature Extraction) และการฝึกสอนโครงข่ายประสาทเทียม (Neural Network Training)

บนแพลตฟอร์ม Edge Impulse Studio ขั้นตอนการประมวลผลข้อมูลสำหรับระบบการมองเห็นด้วยคอมพิวเตอร์ (Computer Vision) ประกอบด้วย 4 ลำดับขั้นตอนหลักตามมาตรฐานอุตสาหกรรม:

ภาพที่ 4.1: แผนภาพแสดง 4 ขั้นตอนการประมวลผลข้อมูล (Data Pipeline Design) บน Edge Impulse Studio: 1. เก็บรวบรวมข้อมูล, 2. จัดสัดส่วน 80:20, 3. ปรับขนาดภาพ, 4. ติดป้ายกำกับ Data Pipeline

4 Labeling Methods

ตอนที่ 2: การจัดสรรชุดข้อมูล

การจัดเก็บและจัดสัดส่วนชุดข้อมูลฝึกสอนต่อชุดข้อมูลทดสอบ (80:20 Ratio)

หนึ่งในความผิดพลาดที่พบบ่อยที่สุดของผู้เริ่มต้นพัฒนาปัญญาประดิษฐ์ คือการนำภาพทั้งหมดไปใช้ฝึกสอนโมเดลโดยไม่มีการแบ่งชุดข้อมูลไว้ทดสอบ ส่งผลให้ได้โมเดลที่มี ภาวะท่องจำข้อมูล (Overfitting) คือเมื่อทดสอบกับภาพเดิมที่เคยใช้สอน โมเดลจะให้ความแม่นยำ 100% แต่เมื่อนำไปติดตั้งใช้งานจริงบนสายพานโรงงาน โมเดลกลับไม่สามารถตรวจจับความผิดปกติของชิ้นงานใหม่ได้เลย

ตามหลักการทางสถิติและการเรียนรู้ของเครื่อง มาตรฐานสากลจึงกำหนดให้แบ่งชุดข้อมูลออกเป็น 2 ส่วนที่แยกขาดจากกัน:

1. ชุดข้อมูลฝึกสอน (Training Set: 80%)

เป็นข้อมูลชุดใหญ่ที่โมเดลใช้ในการคำนวณและปรับค่าน้ำหนัก (Weights & Biases) ภายในโครงข่ายประสาทเทียม เพื่อให้โมเดลสามารถเรียนรู้รูปแบบ (Patterns) และคุณลักษณะเด่นของชิ้นงานแต่ละประเภท

2. ชุดข้อมูลทดสอบ (Testing Set: 20%)

เป็นข้อมูลชุดที่ โมเดลต้องไม่เคยเห็นมาก่อนโดยเด็ดขาดในระหว่างการฝึกสอน ทำหน้าที่เป็น "ข้อสอบกลาง" สำหรับประเมินความสามารถในการสรุปนัยทั่วไป (Generalization Ability) ของโมเดลอย่างเที่ยงตรง

ข้อพึงระวังขั้นวิกฤต: ภาวะข้อมูลรั่วไหล (Data Leakage)

ห้ามถ่ายภาพวัตถุชิ้นเดิมในมุมเดิมติดกันหลายสิบภาพแล้วให้ระบบสุ่มแบ่งเข้าทั้ง Train และ Test เพราะจะทำให้ภาพที่เหมือนกันเกือบทุกพิกเซลหลุดเข้าไปอยู่ในชุดทดสอบ ส่งผลให้คะแนนประเมินความแม่นยำสูงเกินจริง (False High Accuracy) ภาพใน Testing Set ควรเป็นชิ้นงานคนละชิ้น หรือถ่ายในช่วงเวลาและสภาวะแสงที่แตกต่างกัน

ตอนที่ 3: การติดป้ายกำกับและการปรับขนาดภาพ

วิธีการติดป้ายกำกับข้อมูลและการปรับขนาดภาพ (Data Labeling & Preprocessing)

ภาพที่ 4.2: การปฏิบัติการจัดเก็บตัวอย่างภาพชิ้นงานผ่านกล้องดิจิทัล และการตรวจสอบสัดส่วน Train/Test ผ่านแดชบอร์ด Data Acquisition บน Edge Impulse Studio Studio Interface

การเลือกวิธีการติดป้ายกำกับข้อมูล (Labeling Method Comparison)

1. การติดป้ายกำกับภาพรวม (One label per data item)

เป็นการกำหนดป้ายชื่อ 1 ชื่อให้กับภาพถ่ายทั้งภาพ เหมาะสำหรับงาน การจำแนกประเภทภาพ (Image Classification) ในบทที่ 10 เช่น กำหนดให้ทั้งภาพเป็น 'pass' หรือ 'defect'

ตัวอย่าง: sample_01.jpg -> Label: "Normal"
2. การกำหนดกรอบพิกัดวัตถุ (Bounding Boxes)

เป็นการวาดกรอบสี่เหลี่ยมล้อมรอบวัตถุแต่ละชิ้นในภาพ พร้อมระบุป้ายชื่อ เหมาะสำหรับงาน การตรวจจับวัตถุด้วยสถาปัตยกรรม FOMO (Object Detection) ในบทที่ 8 และ 9

ตัวอย่าง: sample_01.jpg -> Box(x=48, y=52, w=16, h=16, label="screw")
ทำไมการประมวลผลบน Edge AI จึงนิยมปรับขนาดภาพเป็น 96x96 พิกเซล?

ภาพความละเอียดสูงระดับ Full HD (1920x1080) มีจำนวนพิกเซลมากกว่า 2 ล้านพิกเซล ซึ่งต้องใช้หน่วยความจำแรมและการประมวลผลมหาศาลเกินขีดจำกัดของระบบสมองกลฝังตัว การย่อขนาดภาพลงเป็น 96 x 96 พิกเซล (RGB = 27,648 ไบต์) ช่วยลดปริมาณการคำนวณลงได้มากกว่า 95% ทำให้บอร์ดสามารถประมวลผลได้เร็วระดับ 30-60 เฟรมต่อวินาที (FPS) โดยยังคงรักษารูปทรงและคุณลักษณะเด่นของวัตถุไว้ได้อย่างเพียงพอ

    # ตรวจสอบเกณฑ์มาตรฐาน 80:20 (ยอมรับความคลาดเคลื่อน +-3%)
    if 77.0 <= train_ratio <= 83.0:
        print("    >> [ผ่านเกณฑ์]: อัตราส่วนสอดคล้องกับมาตรฐาน 80:20")
    else:

1. ในขั้นตอนการออกแบบขั้นตอนการประมวลผลข้อมูล (Data Pipeline) เหตุใดจึงต้องกำหนดสัดส่วนชุดข้อมูลฝึกสอน (Training) ต่อชุดข้อมูลทดสอบ (Testing) ในอัตราส่วน 80:20?
คลิกเพื่อดูแนวคำตอบ
แนวคำตอบ: เพื่อให้มีข้อมูลในปริมาณที่เพียงพอ (80%) สำหรับให้โมเดลโครงข่ายประสาทเทียมเรียนรู้ลักษณะเด่นและปรับค่าน้ำหนักได้อย่างมีประสิทธิภาพ ในขณะเดียวกันก็กันข้อมูลอีก 20% ไว้เป็นชุดข้อมูลทดสอบอิสระที่โมเดลไม่เคยเห็นในระหว่างการสอน เพื่อใช้ประเมินความสามารถในการสรุปนัยทั่วไป (Generalization Ability) และป้องกันภาวะการท่องจำข้อมูล (Overfitting)
2. การเลือกรูปแบบความลึกของสี (Color Depth) ระหว่าง RGB และ Grayscale มีผลกระทบต่อประสิทธิภาพและการทำงานของระบบ Edge AI อย่างไร?
คลิกเพื่อดูแนวคำตอบ
แนวคำตอบ: ภาพแบบ Grayscale มีข้อมูลเพียง 1 แชนแนล (ระดับความสว่างสีเทา) จึงใช้หน่วยความจำและรอบการคำนวณน้อยกว่าภาพ RGB ถึง 3 เท่า เหมาะสำหรับงานที่รูปทรงหรือโครงร่างเป็นปัจจัยตัดสินหลัก (เช่น การตรวจนับจำนวนสกรู) ส่วนภาพ RGB มี 3 แชนแนลสี (แดง, เขียว, น้ำเงิน) แม้จะใช้หน่วยความจำสูงกว่า แต่จำเป็นอย่างยิ่งในงานที่สีมีผลต่อการตัดสินใจ เช่น การตรวจจับผลไม้สุก/ดิบ หรือการคัดแยกสีสายไฟ
3. ภาวะข้อมูลรั่วไหล (Data Leakage) คืออะไร และวิศวกรข้อมูลมีวิธีการป้องกันปัญหานี้อย่างไรในการจัดเตรียมชุดข้อมูล?
คลิกเพื่อดูแนวคำตอบ
แนวคำตอบ: ภาวะข้อมูลรั่วไหล (Data Leakage) คือการที่ข้อมูลตัวอย่างจากชุดทดสอบ (Testing Set) เกิดความคล้ายคลึงหรือซ้ำซ้อนกับข้อมูลในชุดฝึกสอน (Training Set) เช่น การตัดแบ่งเฟรมจากวิดีโอต่อเนื่องเดียวกันเข้าทั้งสองชุด ทำให้คะแนนประเมินความแม่นยำสูงเกินจริง วิธีการป้องกันคือการแบ่งชุดข้อมูลตามสภาพแวดล้อม กลุ่มตัวอย่าง หรือช่วงเวลาการบันทึกที่แยกขาดจากกันอย่างชัดเจน เพื่อให้มั่นใจว่าชุดทดสอบเป็นข้อมูลใหม่จริง ๆ
