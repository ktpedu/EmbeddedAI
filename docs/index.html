ปัญญาประดิษฐ์บนระบบสมองกลฝังตัว (Embedded Artificial Intelligence)

เรียนรู้การประมวลผลโมเดล AI บนอุปกรณ์ปลายทางด้วยบอร์ด Arduino UNO Q สถาปัตยกรรม Dragonwing QRB2210 ร่วมกับแพลตฟอร์ม Edge Impulse Studio

สื่อวีดิทัศน์การสอน
Machine Learning Pipeline • ฝึกสอนโมเดลระดับวิศวกรรม

การฝึกสอนโมเดล AI บน Edge Impulse ทั้งระบบการมองเห็น (Vision) และสัญญาณเสียง (Audio)

ครบครัน 4 สถาปัตยกรรมหลัก: Visual Anomaly (FOMO-AD), FOMO Object Detection, Image Classification และ Keyword Spotting (KWS) คำสั่งเสียงภาษาไทย

ดาวน์โหลด Dataset & Slides
Hardware & Database • บันทึกประวัติ AI อัจฉริยะ

การติดตั้งและประมวลผลโมเดล .eim บนบอร์ดจริง บันทึกข้อมูลลง Database-SQL Brick

คอมไพล์เป็นไฟล์โมเดลเนทีฟ Linux AArch64 ประมวลผลร่วมกับกล้องเว็บแคมหรือไมโครโฟน และจัดเก็บบันทึกประวัติการทำนายผล (Inference Event Logs) ลงฐานข้อมูลในตัวบอร์ดแบบเรียลไทม์
