### 📖 ภาพรวมโครงการ (Project Overview)
คลังทรัพยากรการเรียนรู้และแพลตฟอร์มการจัดการเรียนการสอนแบบดิจิทัลฉบับสมบูรณ์ สำหรับรายวิชา **"ปัญญาประดิษฐ์บนระบบสมองกลฝังตัว" (Embedded Artificial Intelligence)** ตามมาตรฐานการเรียนรู้ระดับมัธยมศึกษาตอนปลายและอาชีวศึกษา โดยมุ่งเน้นการลงมือปฏิบัติจริงบนบอร์ดพัฒนา **Arduino UNO Q** ร่วมกับแพลตฟอร์มคลาวด์ **Edge Impulse Studio**

### 🚀 การติดตั้งและเปิดใช้งานระบบเว็บ (Quick Start)

#### 1. ข้อกำหนดเบื้องต้น (Prerequisites)
- [Node.js](https://nodejs.org/) (เวอร์ชัน 18 ขึ้นไป)
- [Git](https://git-scm.com/)

#### 2. วิธีการรันระบบ (Running the Platform)
1. เปิดเทอร์มินัลหรือ PowerShell ในโฟลเดอร์โครงการ:
   ```bash
   cd web_learning_platform
   ```
2. ติดตั้ง Dependencies (ทำเฉพาะครั้งแรก):
   ```bash
   npm install
   ```
3. เริ่มต้นเซิร์ฟเวอร์:
   ```bash
   npm start
   ```
   *(หรือดับเบิลคลิกที่ไฟล์ `start_server.bat` ที่โฟลเดอร์หลัก)*
4. เปิดเว็บเบราว์เซอร์เข้าสู่ระบบที่:
   ```
   http://localhost:3000   (หรือ http://localhost:3001 กรณีพอร์ต 3000 ไม่ว่าง)
   ```

### 📚 สรุปรายชื่อบทเรียน 12 บท (Curriculum Modules)
1. **บทที่ 1:** การเตรียมความพร้อมระบบและบอร์ดพัฒนา Arduino UNO Q
2. **บทที่ 2:** สถาปัตยกรรมซอฟต์แวร์แบบมอดูล (Modular Brick) และการควบคุมฮาร์ดแวร์พื้นฐาน
3. **บทที่ 3:** การจัดการระบบฐานข้อมูลบนอุปกรณ์ด้วย Database-SQL Brick
4. **บทที่ 4:** การจัดเตรียมชุดข้อมูลและการออกแบบขั้นตอนการประมวลผล (Data Pipeline) บน Edge Impulse
5. **บทที่ 5:** การฝึกสอนโมเดลตรวจจับความผิดปกติจากภาพ (Visual Anomaly Detection: FOMO-AD)
6. **บทที่ 6:** การนำโมเดล .eim ไปใช้งานและการกำหนดค่าไฟล์ app.yaml บนบอร์ดพัฒนา Arduino UNO Q
7. **บทที่ 7:** การประมวลผลโมเดลตรวจจับความผิดปกติจากภาพ และการบันทึกข้อมูลลง Database-SQL Brick
8. **บทที่ 8:** การฝึกสอนโมเดลตรวจจับวัตถุด้วยสถาปัตยกรรม FOMO (Object Detection)
9. **บทที่ 9:** การนำโมเดล FOMO ไปใช้งานและการควบคุมอุปกรณ์ขับเคลื่อน (Actuator)
10. **บทที่ 10:** การพัฒนาและประมวลผลโมเดลจำแนกประเภทภาพ (Image Classification)
11. **บทที่ 11:** การประมวลผลสัญญาณเสียงและการฝึกสอนโมเดลรู้จำคำสั่งเสียง (Keyword Spotting: KWS)
12. **บทที่ 12:** การจำแนกเสียงเฉพาะทางและการบูรณาการระบบ Edge AI เชิงวิศวกรรม
