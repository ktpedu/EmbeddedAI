1. สาระสำคัญและจุดประสงค์การเรียนรู้ (Objectives)
  • สามารถคอมไพล์และดาวน์โหลดไฟล์โมเดลไบนารี .eim (Linux AArch64) จาก Edge Impulse Studio ได้
  • สามารถถ่ายโอนไฟล์ไปยังไดเรกทอรีที่ถูกต้องและกำหนดสิทธิ์รัน (chmod +x) ได้อย่างถูกต้อง
  • สามารถเขียนและแก้ไขโครงสร้างไฟล์ app.yaml ตามมาตรฐานของ Arduino App Lab ได้อย่างสมบูรณ์
2. รายการอุปกรณ์และเครื่องมือซอฟต์แวร์ (Equipment & Tools)
  • บอร์ดพัฒนา Arduino UNO Q
  • ไฟล์โมเดลไบนารี .eim สำหรับสถาปัตยกรรม Linux AArch64
  • โปรแกรม Arduino App Lab และ VS Code Terminal
  • ไฟล์สคริปต์ตรวจสอบโครงแบบ fix_app_yaml.py
3. ลำดับขั้นตอนการปฏิบัติการ (Laboratory Procedures)
1. การคอมไพล์และดาวน์โหลดไฟล์ไบนารี .eim: เข้าสู่แท็บ Deployment บน Edge Impulse Studio เลือกเป้าหมาย Linux (AArch64) กด Build และดาวน์โหลดไฟล์ผลลัพธ์
2. การจัดวางไฟล์และตั้งค่าสิทธิ์ Execution: ย้ายไฟล์ .eim เข้าสู่โฟลเดอร์ /home/arduino/.arduino-bricks/ei-models/ เปลี่ยนชื่อเป็น AnomalyDetection.eim และป้อนคำสั่ง chmod +x เพื่อเปิดสิทธิ์การรัน
3. การเขียนและตรวจสอบไฟล์ app.yaml (fix_app_yaml.py): เปิดไฟล์ app.yaml ตรวจสอบบล็อก services, bricks, dependencies รันสคริปต์ fix_app_yaml.py ตรวจสอบไวยากรณ์และทดสอบเปิดบริการ
4. ตารางบันทึกผลการปฏิบัติการและการสังเกตการณ์ (Data & Results)
รายการตรวจสอบการ Deployคำสั่ง / การตั้งค่าที่ใช้ผลลัพธ์ที่ตรวจพบสถานะ
ตำแหน่งไฟล์โมเดล .eim ls -l /home/arduino/.../ei-models/
สิทธิ์การรันไฟล์ (-rwxr-xr-x) chmod +x AnomalyDetection.eim
ทดสอบรันโมเดลตรงผ่าน Terminal ./AnomalyDetection.eim /dev/video0
ความเร็วการประมวลผล (Inference Latency) วัดเวลาต่อเฟรม (ms)
ผลการตรวจสอบไวยากรณ์ app.yaml python fix_app_yaml.py
5. คำถามท้ายบทปฏิบัติการเพื่อการคิดวิเคราะห์ (Analytical Questions)
1. เพราะเหตุใดจึงต้องป้อนคำสั่ง chmod +x ให้แก่ไฟล์โมเดล .eim ก่อนนำไปใช้งานในระบบลีนุกซ์?
2. หากในไฟล์ app.yaml มีการเยื้องช่องว่าง (Indentation) ไม่ถูกต้อง จะส่งผลกระทบต่อบริการของ Arduino App Lab อย่างไร?
3. อธิบายบทบาทของฟิลด์ dependencies ในไฟล์ app.yaml ว่ามีความสำคัญต่อการรันโปรเจกต์อย่างไร
เกณฑ์การประเมินรูบริก (Rubrics 10 คะแนน):
• การดาวน์โหลดและติดตั้งไฟล์โมเดลพร้อมกำหนดสิทธิ์อย่างถูกต้อง 3 คะแนน
• การเขียนโครงสร้าง app.yaml ที่ถูกต้องและผ่านการตรวจสอบ 4 คะแนน
• การทดสอบรันโมเดลและการบันทึกเวลาตอบสนอง (Latency) 3 คะแนน
