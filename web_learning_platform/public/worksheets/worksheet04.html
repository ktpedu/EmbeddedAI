1. สาระสำคัญและจุดประสงค์การเรียนรู้ (Objectives)
  • เข้าใจกระบวนการบันทึก จัดหมวดหมู่ และคัดกรองข้อมูลภาพสำหรับงานฝึกสอนโมเดล Edge AI
  • สามารถแบ่งสัดส่วนชุดข้อมูล Training Data และ Testing Data ในอัตราส่วน 80:20 ได้อย่างเหมาะสม
  • สามารถออกแบบ Impulse Pipeline เลือกบล็อก Image DSP และวิเคราะห์การกระจายตัวใน 3D Feature Explorer
2. รายการอุปกรณ์และเครื่องมือซอฟต์แวร์ (Equipment & Tools)
  • บอร์ดพัฒนา Arduino UNO Q พร้อมโมดูลกล้อง หรือกล้องเว็บแคม USB
  • บัญชีผู้ใช้งานแพลตฟอร์ม Edge Impulse Studio
  • ชิ้นงานตัวอย่างสำหรับเก็บภาพ (ชิ้นงานปกติและชิ้นงานที่มีรอยตำหนิ)
  • ไฟล์สคริปต์ data_pipeline_check.py
3. ลำดับขั้นตอนการปฏิบัติการ (Laboratory Procedures)
1. การเก็บรวบรวมภาพถ่ายชิ้นงาน (Image Acquisition): ถ่ายภาพชิ้นงานตัวอย่างผ่านเครื่องมือ Data Acquisition ของ Edge Impulse ควบคุมระยะห่าง ความสว่าง และมุมกล้องให้คงที่
2. การจัดสัดส่วน Train/Test Split (80:20): ตรวจสอบสัดส่วนของข้อมูลในโปรเจกต์ให้มีอัตราส่วนการฝึกสอนต่อการทดสอบ 80% ต่อ 20% โดยไม่มีภาพรั่วไหลข้ามกลุ่ม
3. การกำหนดบล็อก Image DSP และสกัดคุณลักษณะ (Feature Extraction): เลือก Color Depth (Grayscale / RGB) ปรับขนาดภาพเป็น 96x96 พิกเซล และกดปุ่ม Generate Features สังเกตการรวมกลุ่มใน 3D Feature Explorer
4. ตารางบันทึกผลการปฏิบัติการและการสังเกตการณ์ (Data & Results)
รายการประเมินชุดข้อมูลเกณฑ์มาตรฐานผลการจัดเตรียมจริงในโปรเจกต์สถานะ
จำนวนภาพชุดฝึกสอน (Train Set) อย่างน้อย 50 ภาพ
จำนวนภาพชุดทดสอบ (Test Set) อย่างน้อย 15 ภาพ (20%)
สัดส่วน Train / Test Split อัตราส่วน 80:20
ความละเอียดภาพใน Impulse Block 96 x 96 พิกเซล
ผลการรัน data_pipeline_check.py ผ่านเกณฑ์มาตรฐานทั้งหมด
5. คำถามท้ายบทปฏิบัติการเพื่อการคิดวิเคราะห์ (Analytical Questions)
1. เพราะเหตุใดจึงห้ามนำภาพที่อยู่ในกลุ่ม Testing Data ไปปะปนในชุด Training Data โดยเด็ดขาด?
2. ในกรณีของงาน Visual Anomaly Detection การแปลงภาพเป็นเฉดสีเทา (Grayscale) มีข้อดีข้อเสียอย่างไรเมื่อเทียบกับภาพสี (RGB)?
3. หากพบว่าจุดข้อมูลใน 3D Feature Explorer มีการกระจายตัวกระจัดกระจายไม่เกาะกลุ่มกัน จะบ่งบอกถึงปัญหาใดและมีแนวทางแก้ไขอย่างไร?
เกณฑ์การประเมินรูบริก (Rubrics 10 คะแนน):
• การถ่ายภาพชิ้นงานที่มีความคมชัด แสงสม่ำเสมอ และไม่มีภาพซ้ำซ้อน 3 คะแนน
• การกำหนดสัดส่วน 80:20 และการตั้งค่า Image DSP Block บน Edge Impulse 4 คะแนน
• การวิเคราะห์คุณลักษณะ 3D Feature Explorer และตอบคำถาม 3 คะแนน
