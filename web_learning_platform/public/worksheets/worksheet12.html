1. สาระสำคัญและจุดประสงค์การเรียนรู้ (Objectives)
  • เข้าใจการตรวจจับความผิดปกติจากเสียงเครื่องจักร (Acoustic Anomaly Detection)
  • สามารถบูรณาการโมเดล AI 2 มอดอล (ภาพและเสียง) ให้ทำงานร่วมกันบนบอร์ด Arduino UNO Q ได้
  • สามารถออกแบบสถาปัตยกรรม State Machine สำหรับระบบโรงงานอัจฉริยะและบันทึกเหตุการณ์ลงฐานข้อมูลได้
2. รายการอุปกรณ์และเครื่องมือซอฟต์แวร์ (Equipment & Tools)
  • บอร์ดพัฒนา Arduino UNO Q
  • กล้องเว็บแคม USB และไมโครโฟน USB เชื่อมต่อพร้อมกัน
  • โมเดลประมวลผลภาพ (Vision Model) และโมเดลประมวลผลเสียง (Audio Model)
  • ไฟล์สคริปต์ multi_ai_live.py และฐานข้อมูล SQLite
3. ลำดับขั้นตอนการปฏิบัติการ (Laboratory Procedures)
1. การเชื่อมต่อเซนเซอร์พหุโมดอล (Vision & Audio Sensor Fusion): ตรวจสอบว่าบอร์ด Arduino UNO Q ตรวจพบทั้งอุปกรณ์กล้อง /dev/video0 และไมโครโฟนผ่าน ALSA audio system
2. การออกแบบตรรกะการตัดสินใจข้ามโมดอล (Multi-Modal Logic): เปิดสคริปต์ multi_ai_live.py ศึกษาการทำงานแบบ State Machine เช่น หากกล้องพบชิ้นงานปกติแต่ไมโครโฟนพบเสียงเสียดสีของแบริ่งผิดปกติ ให้สั่งเตือนภัยระดับสอง
3. การทดสอบจำลองระบบโรงงานอัจฉริยะและการบันทึกประวัติ: ป้อนข้อมูลภาพชิ้นงานพร้อมเปิดเสียงเครื่องจักรปกติและผิดปกติ ตรวจสอบการสั่งตัดการทำงานของรีเลย์ และสืบค้นประวัติในฐานข้อมูล SQLite
4. ตารางบันทึกผลการปฏิบัติการและการสังเกตการณ์ (Data & Results)
สภาวะการทดสอบอินพุตจากกล้อง (Vision)อินพุตจากไมโครโฟน (Audio)การตัดสินใจของระบบบูรณาการสถานะระบบความปลอดภัย
สภาวะปกติสมบูรณ์ ชิ้นงานสมบูรณ์ (Normal) เสียงเครื่องจักรปกติ (Normal)
ตรวจพบข้อบกพร่องทางกายภาพ ชิ้นงานมีรอยแตกร้าว (Defect) เสียงเครื่องจักรปกติ (Normal)
ตรวจพบความผิดปกติของมอเตอร์ ชิ้นงานสมบูรณ์ (Normal) เสียงแบริ่งสึกหรอ (Anomaly)
สภาวะวิกฤติต้องหยุดฉุกเฉิน ชิ้นงานชำรุด (Defect) เสียงแบริ่งสึกหรอ (Anomaly)
5. คำถามท้ายบทปฏิบัติการเพื่อการคิดวิเคราะห์ (Analytical Questions)
1. เพราะเหตุใดการรวมศูนย์ข้อมูลหลายมอดอล (Multi-Modal Sensor Fusion: ภาพ + เสียง) จึงให้ความน่าเชื่อถือสูงกว่าการใช้เซนเซอร์เพียงชนิดเดียว?
2. ในระบบโครงงานบูรณาการ Edge AI การบริหารจัดการทรัพยากรหน่วยความจำ RAM และ CPU ให้รัน 2 โมเดลพร้อมกันอย่างราบรื่นมีแนวทางอย่างไร?
3. อธิบายบทบาทของระบบ Safety Interlock ในกรณีที่ระบบปัญญาประดิษฐ์ตรวจพบความผิดปกติระดับวิกฤติในโรงงานอุตสาหกรรม
เกณฑ์การประเมินรูบริก (Rubrics 10 คะแนน):
• การเชื่อมต่อระบบเซนเซอร์พหุโมดอล (กล้องและไมโครโฟน) สำเร็จ 3 คะแนน
• การเขียนโค้ดและรันระบบบูรณาการ multi_ai_live.py ตามตรรกะ State Machine 4 คะแนน
• การจำลองสถานการณ์ความปลอดภัยและการตอบคำถามคิดวิเคราะห์ 3 คะแนน
