1. สาระสำคัญและจุดประสงค์การเรียนรู้ (Objectives)
  • เข้าใจหลักการทำงานของสถาปัตยกรรม Modular Brick และการสื่อสารระหว่างโปรเซสเซอร์ (IPC)
  • สามารถเขียนโปรแกรมควบคุมแผงไฟ LED Matrix 8x13 บนบอร์ด Arduino UNO Q ได้อย่างถูกต้อง
  • สามารถต่อวงจรและเขียนโปรแกรมตรวจจับสวิตช์ปุ่มกด (Active-Low) พร้อมอัลกอริทึม Software Debouncing ได้อย่างแม่นยำ
2. รายการอุปกรณ์และเครื่องมือซอฟต์แวร์ (Equipment & Tools)
  • บอร์ดพัฒนา Arduino UNO Q
  • โมดูลสวิตช์ปุ่มกด (Push Button) พร้อมตัวต้านทาน Pull-up / Pull-down
  • โมดูลรีเลย์ขับโหลด (Relay Module) และไฟแสดงสถานะ LED
  • ไฟล์สคริปต์ brick_runner.py
3. ลำดับขั้นตอนการปฏิบัติการ (Laboratory Procedures)
1. ศึกษาโครงสร้างคลาส Custom Brick: เปิดไฟล์ brick_runner.py ศึกษาการสืบทอดคลาสของ Arduino App Lab และการจัดระเบียบเมธอด __init__, setup และ loop
2. การเขียนคำสั่งควบคุมหน้าจอแสดงผล LED Matrix: ทดสอบการส่งเฟรมภาพไอคอน READY, AI_ACTIVE และ WARNING ขึ้นแสดงผลบน LED Matrix สังเกตการตอบสนองและความสว่าง
3. การตรวจจับสัญญาณปุ่มกดและการขับรีเลย์: ต่อสวิตช์ปุ่มกดเข้ากับพินที่กำหนด รันสคริปต์ทดสอบการกดสลับสถานะ (Toggle) ตรวจสอบการทำงานของฟังก์ชัน Debounce เพื่อป้องกันสัญญาณเด้ง
4. ตารางบันทึกผลการปฏิบัติการและการสังเกตการณ์ (Data & Results)

5. คำถามท้ายบทปฏิบัติการเพื่อการคิดวิเคราะห์ (Analytical Questions)
1. เพราะเหตุใดสถาปัตยกรรม Modular Brick จึงแยกส่วนการทำงานของโมดูลฮาร์ดแวร์ออกจากโมดูลประมวลผล AI?
2. อธิบายหลักการของ Software Debouncing และหากไม่มีขั้นตอนนี้จะส่งผลกระทบต่อระบบคัดแยกชิ้นงานอย่างไร?
3. อธิบายการทำงานร่วมกันระหว่างโพรเซสเซอร์ MPU (Linux) และ MCU (ARM Cortex-M4) ในการสั่งงานฮาร์ดแวร์
