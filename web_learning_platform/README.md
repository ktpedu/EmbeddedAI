# ระบบเว็บบทเรียนออนไลน์: ปัญญาประดิษฐ์บนระบบสมองกลฝังตัว
## (Embedded Artificial Intelligence Learning Platform)
**Arduino UNO Q & Edge Impulse Studio**

---

### 1. ภาพรวมระบบ (System Overview)
แพลตฟอร์มการจัดการเรียนรู้ออนไลน์ (LMS & CMS) พัฒนาขึ้นโดยเฉพาะสำหรับรายวิชาเพิ่มเติม **"ปัญญาประดิษฐ์บนระบบสมองกลฝังตัว" (Embedded Artificial Intelligence)** รองรับการทำงาน 2 บทบาทหลักตามสิทธิ์การเข้าถึง (Role-Based Access Control: RBAC):
1. **บทบาทนักเรียน (Student Mode):**
   * ศึกษาบทเรียนออนไลน์ พร้อมคำอธิบาย ผลการเรียนรู้ ลิงก์วิดีโอสอน และสไลด์บรรยาย PDF
   * ทำแบบทดสอบออนไลน์: ข้อสอบปรนัยท้ายบท (120 ข้อ), ข้อสอบกลางภาค (20 ข้อ), ข้อสอบปลายภาค (20 ข้อ) พร้อมระบบตรวจคะแนนแบบ Real-time และเฉลยละเอียดเชิงวิชาการ
   * ศึกษาใบงานปฏิบัติการในห้องทดลอง และโจทย์ข้อสอบปฏิบัติ (รวม 120 คะแนน)
   * คลังชุดคำสั่งตัวอย่าง Python และไฟล์คอนฟิกูเรชัน `app.yaml` พร้อมปุ่มคัดลอกโค้ด
   * ดูประวัติคะแนนสอบและสมุดบันทึกผลการเรียนของตนเอง
2. **บทบาทครู / ผู้ดูแลระบบ (Teacher / Admin Mode):**
   * สิทธิ์ **CRUD เต็มรูปแบบ (เพิ่ม, ลบ, แก้ไข)**:
     * **จัดการบทเรียน (Lessons CRUD):** เพิ่มบทใหม่, แก้ไขชื่อ/เนื้อหา/วิดีโอ/สไลด์, ลบบทเรียน
     * **จัดการคลังข้อสอบ (Quizzes CRUD):** เพิ่มข้อสอบใหม่, แก้ไขโจทย์/ตัวเลือก/เฉลยละเอียด, ลบข้อสอบ
     * **จัดการสื่อการสอน (Materials CRUD):** เพิ่มและลบลิงก์สไลด์และชุดข้อมูลภาพ/เสียง
   * **ระบบตรวจประเมินข้อสอบภาคปฏิบัติ (Rubrics Grading):** บันทึกคะแนนข้อสอบปฏิบัติของนักเรียนรายบุคคล (เต็ม 10 คะแนนต่อหน่วย)
   * **สมุดบันทึกผลการเรียนและการวัดผล (Gradebook):** ดูตารางคะแนนรวมทั้งชั้นเรียน และส่งออกเป็นไฟล์ CSV
   * **แดชบอร์ดสถิติ:** แสดงจำนวนบทเรียน คลังข้อสอบทั้งหมด และคะแนนเฉลี่ย
   * **คืนค่าฐานข้อมูลเริ่มต้น (Factory Reset):** คืนค่าข้อมูลเริ่มต้นมาตรฐานบทเรียนและข้อสอบได้ด้วยคลิกเดียว

### 2. โครงสร้างไฟล์ในระบบ (Project Directory Structure)

```
web_learning_platform/
├── data/
│   ├── db.json             # ฐานข้อมูลหลัก (เก็บข้อมูลบทเรียน ข้อสอบ ใบงาน สื่อ และผลคะแนน)
│   └── seed.json           # ฐานข้อมูลสำรองสำหรับคืนค่ามาตรฐานโรงเรียน
├── public/
│   ├── css/
│   │   └── style.css       # ไฟล์ตกแต่งฟอนต์ Sarabun, การเคลื่อนไหว และธีม UI
│   ├── js/
│   │   └── app.js          # คอนโทรลเลอร์ฝั่ง Client ควบคุม State, Role Switch, CRUD และระบบสอบ
│   └── index.html          # หน้าเว็บหลัก Responsive SPA ด้วย Tailwind CSS
├── package.json            # ไฟล์คอนฟิก Node.js และ Dependencies (express, cors)
├── server.js               # เซิร์ฟเวอร์ Express REST API ให้บริการ CRUD และตรวจข้อสอบ
└── README.md               # คู่มือการติดตั้งและใช้งานระบบ
```

### 3. วิธีการเริ่มใช้งานระบบ (How to Run)

1. เปิดหน้าต่าง PowerShell หรือ Terminal ไปที่ไดเรกทอรีโครงการ:
   ```powershell
   cd c:\Users\lenovo\Desktop\EdgeAI\web_learning_platform
   ```
2. รันคำสั่งเริ่มต้นเซิร์ฟเวอร์:
   ```powershell
   npm start
   ```
   *(หรือใช้คำสั่ง `node server.js`)*
3. เปิดเว็บเบราว์เซอร์แล้วเข้าใช้งานที่ URL:
   ```
   http://localhost:3000
   ```

### 4. วิธีการสลับบทบาทและการใช้งาน (Role Switching Guide)

* **ที่แถบเมนูด้านบน (Header Bar):**
  * สังเกตปุ่ม **"สลับบทบาท"** ที่มุมขวาบน
  * เลือก **"นักเรียน (Student)"** เพื่อเข้าสู่โหมดการเรียนรู้และทดสอบ
  * เลือก **"ครู / Admin"** เพื่อปลดล็อกปุ่ม **"+ เพิ่มบทเรียน"**, ปุ่ม **"แก้ไข"**, ปุ่ม **"ลบ"** ในทุกหน้า และเข้าถึงแท็บ **"จัดการระบบ (Admin CMS)"**
